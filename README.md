# Trash to Treasure — A Cleaner, Circular Market

An interactive Three.js experience for EVOKE Zimbabwe, inspired by a lively market in Harare. Explore the market, follow the circular-economy material routes, and see how organic, plastic, and metal waste are sorted separately.

## Run locally

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, or preview it with `npm run preview`.

## Explore

- Drag or touch the scene to rotate the camera; scroll or pinch to zoom.
- Use the camera controls or the location pins to focus on market activities and recovery facilities.
- Select one of the three waste streams in the footer to focus on its bin.
- Start the guided presentation to follow materials through the market and recovery routes.
- Click scene objects for more information.

## Project notes

The scene is built from Three.js geometry and procedural characters. It does not currently include GTA game assets or photorealistic external character models.
